# Example memorial dates file for the Hebrew Memorial Dates widget.
# Copy it to your Documents folder as mem_dates_luach.txt (or choose another
# path in the widget settings) and replace the sample rows with your own.
# Add one entry per line below the header line date,name,type.
# Lines starting with # are comments.
#
# date: a date written as D.M.Y
#   Year up to 5000: the Gregorian date of the event (for example a birth). It is
#   converted to the Hebrew date once, and the event then repeats by the Hebrew calendar.
#   Year above 5000: a Hebrew date (months: 1 = Tishrei ... 12 = Elul,
#   6 = Adar, in a leap year 13 and 14 = Adar I and Adar II).
# name: a name or title of the event
# type: the kind of event (for example: birthday, yahrzeit)
# Lines with errors are skipped; the widget shows their numbers.
# The file must be saved as UTF-8: names may be in any language.
#
# ----------------------------------------------------------------
#
# Пример файла памятных дат для виджета Hebrew Memorial Dates.

#   Год больше 5000: еврейская дата (месяцы: 1 = Тишрей ... 12 = Элул,
#   6 = Адар, в високосный год 13 и 14 = Адар I и Адар II).
# name: имя или название события
# type: вид события (например: день рождения, йорцайт)
# Строки с ошибками пропускаются, виджет покажет их номера.

# date: תאריך בפורמט D.M.Y (יום.חודש.שנה)
